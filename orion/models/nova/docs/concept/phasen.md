# Phasen

Festgehalten aus der Diskussion. Kein Netz, kein Lauf. Jede Phase ist ein eigener Lauf. Die Note der vorigen Phase muss auf den Tagen halten, die nicht geübt wurden.

1. Die nächste Kerze: Hoch, Tief oder noch nicht. Eingabe ist die Kerze selbst, wie in `start.md`. Laufumgebung JAX. Netz: die volle Aufmerksamkeit aus JAX. Aufgabenform wie in `aufgabe.md`. Daneben derselbe Lauf ohne das kurze Nachstellen, damit sichtbar ist, ob die Aufgabenform die Note verändert.
2. Dieselbe Aufgabe, dasselbe Netz-Ziel, Mamba aus einer JAX-Bibliothek. Liegt dieser Lauf vorn, bleibt er.
3. Die weiteren Eingabegruppen aus `start.md`, eine nach der anderen.
4. Der Preis der nächsten Kerze. Eigene Gewichte. Erst wenn die Note aus Phase 1 auf ungesehenen Tagen hält.
5. Weitere Kerzen vorstellen. Eigener Lauf. Die Note der ersten Kerze muss dabei halten. Dieser Lauf benennt die späteren Wechsel.
6. Die Order. Fills der eigenen Order liegen nicht in den Daten. Diese Phase wartet auf eine Fill-Rechnung.
